# Icons

Single-ink line icons, 48×48, 2px round stroke in `ink` light (#1d1d1b). `<img>` can't inherit colour: in dark theme apply `filter: invert(.94)` or set them on a light `paper-raised` chip.

- `pothole.svg` — Roads: potholes, broken paving. IssueCard media and category pickers.
- `streetlight.svg` — Lighting: lights out or flickering.
- `waste.svg` — Waste: overflowing bins, fly-tipping, missed collection.
- `water.svg` — Water: leaks, flooding, blocked drains.
- `tree.svg` — Green spaces: fallen branches, overgrowth, parks.
- `graffiti.svg` — Graffiti and vandalism.
- `pin.svg` — Location: “Pinned to the map”, location pickers, empty map states.
- `camera.svg` — Add a photo; the “Snap and send” step.
- `megaphone.svg` — Routing and announcements; council updates.
