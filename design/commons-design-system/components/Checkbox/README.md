# Checkbox

A small square box with a label, used for consent lines and privacy choices.

- Consumer provides: `label` (text or a node with a link), and native props (`checked`, `defaultChecked`, `onChange`, `required`).
- Label text is `caption` in `ink-muted`; links inside it are `ink` at weight 500.
- Privacy defaults lean private: “Keep my name private on the public map” starts checked.
